# 问茶研究室 · 面积看得见

面向五年级学生的互动数学网站。首屏插画现在是固定在一屏内的独立菜单，不能纵向滚动，提供“动手探索”“运动方法”“闯关练习”三个入口；其他页面仍可滚动。各页面通过网址片段切换，可用浏览器返回键回到上一页。进入动手探索时默认显示长和宽都是 5 cm 的蓝色长方形；方格纸上方可切换到平行四边形、直角三角形或等腰梯形。四种图形使用相同的 10 × 10 方格、数值条、面积卡片和练习，各自记住设置的尺寸。长方形面积是长 × 宽，平行四边形面积是底 × 高，三角形面积是底 × 高 ÷ 2，等腰梯形面积是（上底＋下底）× 高 ÷ 2。平行四边形模式可拖动竖向虚线到左侧或右侧正确位置，按“剪”验证；剪对后拖动三角形到另一侧缺口，按“拼”验证。等腰梯形模式也可沿上底左端点或右端点竖切，再把剪下的三角形翻转、拖到另一侧缺口，拼成同高的长方形。三角形模式可按“复制三角形”在右下角生成同尺寸的淡蓝色三角形，将它拖到虚线缺口后按“拼”验证。错误时显示红色错叉，拼对后显示绿色对勾；两种反馈都会在 2 秒后消失。平行四边形底边限制为 1–9 cm，确保有竖切空间；高的整数上限随底改变，满足「高 ≤ 底 × tan a」（约 59° 的最小夹角）。等腰梯形的上底为 1–9 cm，下底须比上底长，高为 1–10 cm。旁边的数值条各固定 10 格，蓝格表示当前长度，白格表示剩余长度；拖动紫色圆点可调节尺寸，图形与面积会立即更新。支持鼠标、触屏和键盘调节尺寸，也可恢复当前图形的初始尺寸。运动方法页另有平移、旋转和轴对称的介绍。

闯关练习页将面积题卡放在中央；“再来一题”依次生成平行四边形、三角形、等腰梯形、长方形题目，并清空上一题的输入与反馈。题目边长可超过 10 cm，初始生成范围为 1–20 cm；题库用完会继续扩大范围。浏览器会记录已出过的题型与尺寸组合，避免重复。题目尺寸和探索页的滑块互不影响。

## 本地运行

项目仅使用原生 HTML、CSS 和 JavaScript。顶部导航由 `site-header.js` 中的公用 Web Component 提供，构建时会一起复制到 `dist/`。可直接用浏览器打开 `index.html`，或在项目目录运行：

```sh
python3 -m http.server 8000
```

访问 `http://localhost:8000`。

## 检查和构建

```sh
npm run check
npm run build
```

构建产物位于 `dist/`。

## 部署到 Cloudflare Pages

仓库包含 `wrangler.toml`，构建命令为 `npm run build`，输出目录为 `dist`。也可以使用 Wrangler 手动部署：

```sh
npm run build
npx wrangler pages deploy dist --project-name shape-motion-area
```

网站没有服务端依赖，也不需要密钥。
